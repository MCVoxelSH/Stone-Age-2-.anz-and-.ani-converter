Usage: <br />
       ```python anz_to_png.py <input-folder>```<br />
       ```python anz_to_png.py <input-folder> -o <output-folder>```<br />
       ```python anz_to_png.py <file.anz>```<br />
       ```python anz_to_png.py <input-folder> --no-frames --atlas```<br />

You can search for "arguments" in the script to see more arguments.

dependencies: Pillow - installation: ```pip install Pillow```
